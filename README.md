# MyGitPages

Standalone HTML versions of my Cursor canvases — open in any browser, **no Cursor required**. Published via GitHub Pages.

**Live site:** https://himanshu2405.github.io/MyGitPages/

Each canvas lives in its own folder with an `index.html`. The root `index.html` is a landing page that links to all of them with their live URLs.

## Regenerating the site

All pages are generated by `generate_html.py` (a copy lives in this repo). To rebuild every page + the landing `index.html` + `.nojekyll`:

```bash
python3 generate_html.py
```

By default it writes into the script's own directory (this repo root). To write elsewhere, pass a target directory:

```bash
python3 generate_html.py /path/to/output
```

The landing-page URL shown next to each canvas comes from `BASE_URL` in the script (overridable with the `PAGES_BASE_URL` env var).

## Adding a new canvas

1. Add a `make_<name>()` function in `generate_html.py`.
2. Add `("<slug>", make_<name>)` to the `CANVASES` list.
3. Add an entry to `INDEX_SECTIONS` so it shows on the landing page.
4. Re-run `python3 generate_html.py`, commit, and push.
